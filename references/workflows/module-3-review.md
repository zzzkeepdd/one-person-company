# 复盘宪法流程

## 触发

项目交付验收后，Hermes统领提醒："项目已完成，是否复盘？"
- L1/L2: 可选。提醒 1 次，用户拒绝即跳过。
- L3: 强制提醒。提醒 3 次，用户可明确拒绝跳过。

## 流程

### Phase 1: 复盘辩论

辩论裁判以复盘模式创建追责方（管理/流程视角）和辩护方（不可抗/一次性问题视角），2 轮上限。1 轮无新争议可提前收敛。

### Phase 2: 复盘裁决

裁判裁决四类结论：
1. **方案/边界问题** → 记录到项目知识库
2. **流程违规** → 更新违规记录（1-2次静默，3次提醒，5次严重警告）
3. **规则空白** → 生成宪法条款草案
4. **外部不可抗力** → 仅记录，不追责

### Phase 3: 宪法半自动草案生成

裁决Agent 根据第 3 类结论自动生成宪法条款草案：
- 格式：一句话规则 + 适用角色 + 触发条件 + group（原子组）
- 写入 `constitution/proposals.md`（追加模式）
- 不立即生效

### Phase 4: 用户确认 → 合并

用户确认后：
1. 将 proposals.md 中已确认的条款合并到 management-rules.md
2. 合并前按 ID 去重检查
3. 已覆盖规则 → 不写入宪法，改更新 violation-records.md
4. proposals.md 合并后清空，加 `<!-- merged: {date} -->` 注释

### Phase 5: 宪法瘦身提醒

- 超 25 条 → 自动提醒用户
- 生成"建议删除清单"（不自动删除）
- M01 标记 immutable，不可删除
- 原子组保护：同 group 的条款必须全留或全删

### Phase 6: 分层注入

按角色元数据裁剪宪法条款，只注入相关角色到后续项目。
