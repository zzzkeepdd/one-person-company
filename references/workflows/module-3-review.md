# 复盘宪法流程

## 触发
项目交付验收后，Hermes统筹提醒："项目已完成，是否复盘？" 用户同意才启动。

## 流程

### Phase 1: 复盘辩论
辩论裁判以复盘模式创建追责方（管理/流程视角）和辩护方（不可抗/一次性问题视角），2轮上限。1轮无新争议可提前收敛。

### Phase 2: 复盘裁决
裁判裁决四类结论：
1. **方案/边界问题** → 记录到项目知识库
2. **流程违规** → 更新违规记录（1-2次静默，3次提醒，5次严重警告）
3. **规则空白** → 写入宪法新条款
4. **外部不可抗力** → 仅记录，不追责

### Phase 3: 宪法更新
- `constitution/management-rules.md` 追加新条款（附着适用角色元数据）
- `constitution/violation-records.md` 更新违规计数

### Phase 4: 分层注入
按角色元数据裁剪宪法条款，只注入相关角色到后续项目。
