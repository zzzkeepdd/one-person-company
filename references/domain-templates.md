# 领域维度模板

> 预澄清后，识别需求领域，注入对应模板。从"被动追问填空"变"主动提案改错"。
> 模板提供默认值，用户只需改不符合的部分。未覆盖领域：预澄清时现场定义维度。

## 使用规则

1. 预澄清结束后，根据用户需求关键词匹配模板
2. 注入模板的默认维度值到商议摘要中标注为 [模板默认]
3. 用户说"全部默认"=全部接受，直接进入辩论
4. 用户改任意维度值=按修改后值辩论
5. 未匹配到模板=预澄清时现场定义维度，辩论后自动补充本节

## 模板：量化交易平台

```yaml
dimensions:
  策略层:
    默认: "双均线+RSI+MACD+布林带+网格+冰山+动量突破+套利 8策略"
    说明: "策略列表、AI可调参数"
    攻击点: "策略冲突时优先级规则是什么"
  资金层:
    默认: "本金=5000U可手动调整，独立于账户余额，亏损上限=本金"
    说明: "资金隔离、调整入口、止损规则"
    攻击点: "本金用完是否自动全部平仓"
  风控层:
    默认: "5%硬止损，手动风控滑块可覆盖，两者同时触发时手动优先"
    说明: "止损规则、手动调节入口"
    攻击点: "手动风控和自动止损同时触发谁优先"
  数据层:
    默认: "OKX WebSocket实时行情，DeepSeek API分析信号"
    说明: "行情源、断网处理、AI分析频率"
    攻击点: "交易所断网时策略如何处理持仓"
  UI层:
    默认: "PyQt6桌面程序，MUJI极简风格（圆角卡片/柔和渐变/emoji图标/活泼不乱）"
    说明: "框架、风格、交互逻辑"
    攻击点: "设置页入口在哪，本金调整交互方式是什么"
  部署层:
    默认: "本地运行，24h服务器部署"
    说明: "运行环境、保活、日志"
    攻击点: "服务器重启后策略状态如何恢复"
```

## 模板：数据管道/ETL

```yaml
dimensions:
  数据源:
    默认: "REST API/CSV文件，支持增量拉取"
    说明: "数据来源、格式、频率"
    攻击点: "数据源返回格式变更如何检测"
  转换:
    默认: "pandas清洗+验证，异常行隔离不丢弃"
    说明: "清洗规则、验证、异常处理"
    攻击点: "百万行数据OOM怎么处理"
  输出:
    默认: "写入数据库/CSV，附带元数据(时间戳+行数)"
    说明: "输出目标、schema、幂等性"
    攻击点: "写入中途失败是否留下脏数据"
  调度:
    默认: "cron/手动触发，运行时锁防并发"
    说明: "调度策略、监控、告警"
    攻击点: "前一次未跑完新调度触发怎么办"
```
