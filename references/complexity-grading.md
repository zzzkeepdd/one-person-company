# 复杂度分级

## 判定标准

| 维度 | 简单 | 中等 | 复杂 |
|------|------|------|------|
| 用户可见产品 | 否（API/库/CLI无UI） | 是（网页/App界面/GUI） | 是+品牌/设计要求 |
| 新文件数 | < 5 | 5-15 | > 15 |
| 外部API | 无 | 1-2个 | 3+ |
| 并发/安全 | 无需考虑 | 基础安全 | 复杂并发/多角色权限 |
| 数据模型 | 无/单表 | 2-3表关联 | 复杂模型/迁移 |
| 用户交互 | 无UI/内部 | Web单页/CLI | 多页面/复杂交互 |

## 阈值
- 简单: 用户可见产品=否 且 全部其他维度在"简单"列
- 复杂: 任意维度在"复杂"列
- 中等: 其他全部情况（用户可见产品=是 → 至少中等，即使其他维度全部简单）
- **安全网规则：用户可见产品=是 → 至少判为中等，必须走完整模块二验收链，不准走简化流程**

## 分流
- 简单 → 跳过辩论，验收链必走
- 中等 → 预澄清+1轮辩论+Codex TDD+验收链
- 复杂 → 预澄清+3轮辩论+裁决+Codex TDD+验收链+复盘必提醒
